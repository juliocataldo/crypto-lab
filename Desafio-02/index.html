Desafio 5 — Sistema Híbrido

Master bônus
Defesa em profundidade — sem flag fixa
Implemente você mesmo um sistema em camadas (Hash + AES + RSA) e proteja uma mensagem para um colega. Este desafio é autoavaliado.
$ openssl genrsa -out chave_privada.pem 2048 $ openssl rand -hex 32 > chave_aes.hex $ openssl enc -aes-256-cbc -pbkdf2 -in msg.txt -out msg.aes -k "$(cat chave_aes.hex)"
